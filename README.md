UI (User Interface):

-Refers to the visual and interactive elements of the application (the "look and feel").

-Includes colors, typography, buttons, icons, and modern card components (such as the Shadcn/ui-inspired card designs implemented in this project).

-In short: It is how the application looks.

UX (User Experience):

-Refers to the overall feel, usability, and how easily users can navigate and interact with the application.

-Focuses on application logic, fast filtering, seamless transitions, and ensuring a smooth, intuitive user journey.

-In short: It is how the application works and feels.
